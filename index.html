§01 / 立论 · WHY

一个 exe，就是全部交付

网管的时间不该花在找工具、装环境、被拦截、写解释上。这台机器可能刚重装完，可能没有网络，可能连你的 U 盘都认不出来——它仍然要能在十分钟内回到可交付状态。

  1. 01

    单文件即交付

    没有安装包、没有服务、没有驱动、没有第三方 DLL。渲染、规则引擎、二维码、压缩解码全部编进同一个 exe，进程退出即散场。

  2. 02

    零依赖是承诺，不是营销

    只碰 Win32 与 Windows SDK。QR 编码器、INFLATE 解码、YARA 子集、dHash 感知哈希、Winapp2 解析器都是手写的——所以它能在一台什么都装不上的机器上跑。

  3. 03

    说真话优先于“看起来成功”

    权限不够就报权限不够，逐项标注 access denied；跳过就说跳过，失败就列失败。宁可交一份不好看的报告，也不伪造一次成功。

  4. 04

    可逆才算做完

    动之前先备份成 TSV，动之后能撤销：流氓软件清理按逆序回放，Windows 优化 40 项可逆，更新锁定留一键还原。写完就回不去的功能，不做。

“蛹里发生的改变，外面看不见——编译期允许静默。”

§02 / 三件重器 · FLAGSHIP

三种最常被叫去现场的场景

不是功能清单。是三个真实发生过很多次的开场白：“这台机器被装了东西”、“帮我连一下那台服务器”、“新机器要进内网”。

purg.scan · purg.rules · purg.yara · purg.homepage · purg.wulock

净化中心

13 个检测点同时看：进程、服务、驱动、内核模块、隐藏进程、自启动、计划任务、Shell 扩展、输入法、文件关联、浏览器扩展、hosts、代理。四步判定，动之前先备份成 purg-backup.tsv，撤销按逆序一条条回放。

  • 396 条签名 + 1130 条目录特征，双源在线更新、SHA256 校验
  • 111 进程 / 279 服务 / 198 微软签名驱动实测，0 假阳性
  • 自带 YARA 子集引擎与可视化规则构建器，规则不进在线更新层

net.sessions · net.tunnel · net.serial

远程终端

用 Windows 自带的 OpenSSH，不塞第二个客户端。会话（SSH / SFTP / Telnet）存进 netadmin-sessions.ini，端口转发生成 ssh -N，串口监视器按 DCB 配置收发。口令从不落盘——交互式输入或公钥，没有第三种。

  • 三种转发 -L / -R / -D，启停与实时状态都在一张表里
  • 串口：COM 枚举、参数配置、监视与发送即读
  • 交互式串口 TUI 暂缓——先给能用的，再给好看的

net.mesh

组网助手

自建 headscale 的入网引导。粘一串 NATBMESH1|server|preauth-key，或者扫一个自己当场生成的二维码：本机零依赖 QR 编码器（字节模式、ECC M、v1–v10），识别客户端、静默安装、tailscale up、回读状态，一条龙。

  • 密钥掩码显示，落盘前 DPAPI 加密
  • 二维码经 zxing-cpp 往返解码验证，214B 正确拒绝
  • 入网 / 退网 / 节点列表 / 登出重置都在一处

§04 / 扩展 · PLUGIN

加一个模块，只要三步

建一个 .cpp、实现 IModule、写一行 REGISTER_MODULE。build.bat 自己通配 src/modules/*.cpp，构建脚本不用动；侧栏与 --list 立刻出现。

src/modules/mymod.cpp C++20 
#include "../module.h"

class MyMod : public IModule {
public:
  const wchar_t* Id()    const override { return L"demo.mymod"; }
  const wchar_t* Group() const override { return L"我的工具"; }
  ModuleKind Kind() const override { return ModuleKind::Inventory; }

  void Run(ModuleContext& ctx, ModuleResult& out) override {
    ctx.Report(0, L"Working...");    // 进度回调
    ctx.Log(L" 进日志面板");       // 日志回调
    if (ctx.Cancelled()) return;   // 可取消

    ModuleRow r;
    r.c1 = L"Name"; r.c2 = L"Value";
    out.rows.push_back(r);
    out.summary = L"Done: 1 item";
  }
};

REGISTER_MODULE(MyMod);

框架核心（module / cli / qr / lang / ui）扩展时不用碰。

接口要点

Id()唯一 ID，CLI 用，如 net.portscan
Group()侧栏分组名，同名自动归组
Kind()Inventory / Cleaner / Action / Tweaks / Console
NeedsElevation()提示以管理员运行，而非静默失败
Actions()扩展动作按钮：主操作 / 撤销 / 溢出菜单
SupportsUndo()可撤销的 Tweaks 必须实现 Undo()

模块返回四列表格、摘要、提示与能否清理；ModuleContext 提供 Log()、Report(pct,msg)、Cancelled()。UI 不认识任何具体模块——所以放进去就长得对。

源码结构 · ★ 为框架核心，扩展时不用碰

src/
├─ module.h/.cpp   ★ 插件接口与注册表
├─ cli.cpp         ★ 从注册表派发命令

├─ lang.h/.cpp     三语查找表 · 二分查找
├─ ui/             ★ 主题 / 缩放 / 全自绘
